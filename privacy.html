Política de
privacidade.

Última atualização: 14 de outubro de 2026

O FSync é um aplicativo pessoal e auto-hospedado para criar backups de pastas selecionadas e enviá-los ao Google Drive. Esta política descreve o tratamento de dados pelo aplicativo e por este site informativo.

1. Responsável e contato

O projeto é mantido por Lucas, desenvolvedor do FSync. Dúvidas sobre privacidade, acesso ou exclusão de dados podem ser enviadas para lucasmafilzodacosta@gmail.com. Em instalações próprias, o operador do servidor controla as configurações e os dados armazenados nessa instalação.

2. Dados utilizados

  • Arquivos de backup: conteúdo das pastas selecionadas pelo operador, compactado em arquivos ZIP e enviado à pasta de destino configurada no Google Drive.
  • Configurações e histórico: nomes e caminhos das pastas, agendamentos, identificadores dos trabalhos e arquivos no Drive, datas, status e informações de erro.
  • Autorização Google: tokens OAuth necessários para acessar o Drive e renovar a autorização, sem solicitar ou armazenar a senha da conta Google.
  • Discord, quando utilizado: identificadores de usuários autorizados, configurações de canais e informações relacionadas aos comandos e às notificações de backup.

3. Acesso ao Google Drive e finalidade

O FSync utiliza a API do Google Drive para enviar arquivos de backup e gerenciar os backups registrados pelo aplicativo, incluindo o envio de backups antigos à lixeira quando uma política de retenção é configurada.

A integração solicita o escopo https://www.googleapis.com/auth/drive. Essa permissão é ampla e permite acesso aos arquivos do Drive; não é tecnicamente limitada apenas aos arquivos criados pelo FSync. O uso pelo aplicativo é destinado às operações de backup descritas nesta política.

Os dados não são vendidos nem utilizados para publicidade, criação de perfis comerciais ou treinamento de modelos de inteligência artificial. O uso e a transferência de informações recebidas das APIs do Google pelo FSync seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Compartilhamento

Os arquivos de backup são enviados ao Google Drive da conta autorizada. Quando o bot está habilitado, o Discord processa comandos e, se configurado, recebe notificações com o nome da origem, o identificador do trabalho e seu resultado. Mensagens de erro podem conter detalhes técnicos, inclusive caminhos de arquivos; use canais com acesso restrito.

As mensagens ficam visíveis para quem tem acesso ao canal. O FSync não oferece compartilhamento público dos backups por este site. Google, Discord e o provedor de hospedagem do site tratam dados conforme suas próprias políticas: Google, Discord e GitHub.

5. Armazenamento e segurança

Configurações e histórico ficam em um banco SQLite no servidor do operador. Tokens OAuth ficam no armazenamento persistente dessa instalação. Os backups ficam no Google Drive conectado. Arquivos temporários de compactação são removidos pelo fluxo normal de execução; interrupções inesperadas podem exigir limpeza pelo operador.

A API utiliza uma chave de acesso e o bot verifica usuários autorizados. Proteger o servidor, os volumes, as credenciais e os canais do Discord é responsabilidade do operador. O FSync não oferece criptografia adicional do conteúdo do ZIP nem garantia absoluta contra perda ou acesso indevido.

6. Retenção, exclusão e revogação

Os backups permanecem no Google Drive até a exclusão pelo usuário ou aplicação de uma política opcional de retenção. A retenção envia backups antigos à lixeira; a exclusão definitiva segue as ações do usuário e as regras do Google Drive.

Você pode interromper agendamentos, excluir backups diretamente no Drive e revogar o acesso do FSync em Conexões da Conta Google. Revogar o acesso impede novas operações autorizadas, mas não apaga backups já enviados, registros locais ou mensagens do Discord.

Para excluir tokens, configurações e histórico locais, o operador deve remover os dados correspondentes da instalação. Mensagens do Discord precisam ser removidas separadamente. Para solicitações relacionadas à instalação pessoal do responsável, utilize o contato desta política.

7. Este site

Este site é estático e informativo: não tem login, formulário de coleta, cookies próprios ou scripts de análise. A hospedagem pelo GitHub Pages pode registrar informações técnicas de acesso, como endereço IP, conforme a política do GitHub. Nenhum backup ou token é disponibilizado neste site.

8. Atualizações

Esta política pode ser atualizada para refletir mudanças no aplicativo. A versão atual e a data da última alteração permanecerão disponíveis nesta página.
